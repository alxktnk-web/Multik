# Multik — действующий контракт интерфейса

База 25.10.2026, runtime `c771eb8`. Это единственная текущая UI-спецификация;
прежние итерации сохранены в [архиве](../history/lighttable-UI_CONTRACT-pre-baseline.md).
Поведение и ограничения — [PRODUCT_SPEC](PRODUCT_SPEC.md), проверки — [ACCEPTANCE](ACCEPTANCE.md).

## Визуальные правила

Тёмный тёплый серый фон, полупрозрачные поверхности, приглушённый sage-зелёный акцент,
светлые тонкие SVG-иконки одного семейства. Локальный Manrope; короткие английские
подписи, минимум текста вокруг фотографии. Экран должен отдавать приоритет фото,
а не постоянным вспомогательным панелям. Иконки — из существующего `ui/icons.ts`
(Lucide/Feather, лицензия в third_party), не emoji и не случайные новые стили.

Переключение инструмента **не меняет положение или размеры stage/canvas**.
В landscape постоянно зарезервирована правая колонка 44px; рамка stage 12px.
Регулировка максимально длинная по доступной высоте; не превращать её в короткий
ползунок под маленьким блоком. Значки компактны, при коротком экране их область
может быть меньше 44px: это текущий компромисс, см. K06 в KNOWN_ISSUES.

## Поверхности и навигация

| Поверхность | Что отображается / действие |
|---|---|
| Mixes (главная) | Крупные превью существующих миксов; создание Mix/Roll, отдельная вкладка Library. Исходные плёнки — вспомогательный раздел Use existing rolls, не главная галерея. |
| Импорт | Сразу запрос native picker, без собственного меню «камера/файлы». 06/12/24/36 как сегменты, 12 по умолчанию; дата/время как редактируемое имя; превью выбора, overflow и явный прогресс. Next Roll → Expose в мастере двух плёнок. Системное меню iOS приложению не подчиняется. |
| Library (галерея) | Сохранённые независимые варианты; сердце на карточке убирает membership. Внизу Removed · Undo (8s). Карточка открывает свой неизменный snapshot. |
| Mixes (View) | Свайп листает пары обеих плёнок. В landscape две полные боковые ленты; выбор кадра меняет один индекс. |
| Library (View) | Свайп листает только сохранённые варианты, в том числе после редактирования/перезапуска. Полные исходные ленты скрыты. |
| Library (редактирование) | В Move/Levels/Halo по одному текущему исходнику с каждой стороны для выбора слоя. Замены исходников через эти миниатюры нет. |
| Чистый просмотр | Короткий неподвижный tap в View скрывает/возвращает кнопки и ленты. Размер и положение фото те же; свайпы остаются внутри текущего пространства. Длинный tap, drag, pinch и редактирование не скрывают UI. Важные ошибки/Undo удаления не теряются. |

Два прямых входа: значок плёнки — Mixes, коллекция фотографий — Library.
Выделение показывает текущий контекст. Открытие окна коллекций само по себе не
подменяет текущий снимок; контекст меняется при открытии карточки.

## Ориентации

**Portrait:** всегда просмотр; поворот композиции, сердце, экспорт; прямые кнопки
Mixes/Library. Нет редакторских шкал, перемещения/масштабирования слоя или film rails.

**Landscape:** постоянная одна левая колонка сверху вниз:

1. Mixes (film)
2. Library (collection)
3. View (eye)
4. Move (four arrows)
5. Levels
6. Halo
7. Heart
8. Save to Photos
9. Rotate 90°
10. Looks (stack)

Справа — только активная шкала Levels/Halo. Looks — единственное раскрывающееся
меню инструментов, снизу рядом со своей кнопкой; Original / Film / Dense / Clear.
У обычного редактора нет постоянных Cancel/Done/Undo/Info/Pro-кнопок.
Update появляется на главной только при доступном обновлении, не через Info/⋯.

## Семантика инструментов

- View фиксирует слои: горизонтальный swipe — навигация. Выход в View завершает RAM-жест и сохраняет по явной границе. При ошибке черновик остаётся.
- Move включает drag x/y и pinch масштаба выбранного слоя; viewport не двигается.
- Levels меняет входной CIELAB L* только выбранного слоя. На фото три зоны black/mid/white, вертикальный drag; справа тонкая шкала с тремя точками дублирует управление и показ. Легенды нет. Pinch не масштабирует в Levels.
- Выбор второго исходника сохраняет активный инструмент и показывает его значения. Повторный tap активного инструмента не переводит скрыто в Move.
- Halo меняет силу гало текущей композиции; в Clear не действует и кнопка недоступна. Radius/threshold/XY скрыты из пользовательского интерфейса.
- Rotate поворачивает **всю композицию**, не выбранный источник; Levels и другие правки сохраняются.
- Heart контурный для нового состояния; сохранение создаёт отдельный вариант. Заполненное сердце снимает membership конкретного состояния, с Undo. Открытый снимок не исчезает.
- Save — прямой native Share без внутреннего окна разрешений/Download. Если подготовка исчерпала активацию Safari, повтор тем же значком отправляет готовый файл. Системное Save Image выбирает пользователь.
