# Multik

PWA для двойной экспозиции на iPhone: две плёнки на световом столе, индивидуальная настройка фотографий и сохранение редактируемых вариантов. Vanilla TypeScript, Vite, WebGL2, IndexedDB.

**Рабочая база:** `baseline-2026-10-25`. Это точка возврата для дальнейших исправлений и улучшений, не заявление «ошибок нет» и не запрет развивать приложение. [Паспорт базы и проверки](docs/lighttable/BASELINE.md).

**Действующее приложение:** https://multik-photo-room.alexanderhot.chatgpt.site/lighttable/ — Sites, существующий доступ владельца. Фото хранятся в браузере на этом адресе, не в GitHub. Корневой адрес сохраняет исторический Classic. GitHub Actions проверяет код и сборку, **не публикует сайт**.

## Локальный запуск

Node.js **22**, npm. Из корня репозитория:

```sh
npm ci --include=dev
npm run dev
```

Открыть адрес Vite с **`/lighttable/`**. `/` — Classic, это не текущая рабочая поверхность.

```sh
npm test
npm run build
npm run preview
```

`npm run build` проверяет TypeScript и собирает `dist/`: неизменный Classic из `deployment/classic-baseline.tar.gz` + актуальный `/lighttable/`. Не удалять архив и не подменять корневой сайт одной сборкой Lighttable.

Браузерные проверки требуют установленного Chromium. Активные сценарии и конкретные требования к окружению — в [ACCEPTANCE.md](docs/lighttable/ACCEPTANCE.md); не все исторические npm-скрипты отражают современный UI.

## Что есть в рабочей базе

- Mixes с двумя плёнками и отдельная Library сохранённых вариантов.
- Portrait — просмотр; landscape — View / Move / Levels / Halo / Looks, поворот, сердце и экспорт.
- Levels меняет **CIELAB Lightness L\*** каждого исходника отдельно. Move перемещает и масштабирует выбранный слой.
- Тап в View скрывает/возвращает интерфейс без изменения геометрии фото.
- Сердце сохраняет отдельное состояние; старые варианты остаются неизменными. Снятие лайка предлагает `Removed · Undo`.
- Save to Photos формирует JPEG с длинной стороной до 4000 px и вызывает системное меню iPhone. Safari иногда требует повторного тапа после подготовки файла.
- Импорт 6 / 12 / 24 / 36 кадров (12 по умолчанию), локальное хранение, собственный service worker и явное Update.

## Как улучшать без регрессий

Небольшая ветка на одну задачу → точечная правка → подходящие проверки → обновление затронутых документов → review/commit. Изменение дизайна не даёт разрешения менять формулы, модель данных или смысл жестов. Крупная переработка требует отдельного обоснования, а не начинается автоматически.

Смена адреса сайта не переносит библиотеку. Полного резервного экспорта/синхронизации проекта сейчас нет. Тесты Chromium не доказывают плавность, цвет или работу системного Photos на iPhone. [Короткая аппаратная приёмка](docs/lighttable/ACCEPTANCE.md#проверка-на-iphone).
